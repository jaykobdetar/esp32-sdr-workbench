This is a modified source distribution, prepared 2026-11-11 from the ESP32 SDR research optimized-v2 release. It is not an official ESPARGOS release.

* Upstream: https://github.com/ESPARGOS/esp-sdr
* Baseline commit: `a8eaac1758d7567be9d6e82698f36f025573cb62`
* Upstream license: GPL-3.0-or-later, retained in LICENSE. Existing file notices remain. Project additions/modifications are distributed under GPL-3.0-or-later; this is not an MIT relicensing.
* Development SDK: https://github.com/espressif/esp-idf at `25fe69f946311abdaf9ad56591f25fedbc20ac98` (development 6.2). SDK and compiler are external and not bundled.
* Vendored ESP-DSP: https://github.com/espressif/esp-dsp at `a53a0756833c045311ea1d79a2badf495cdfde4c`. Its Apache-2.0 LICENSE and copyright headers remain. Included CMake/Kconfig/component metadata and modules are unmodified; example applications/media, docs, tests outside modules and Git metadata are omitted. Some module test include files are build dependencies and remain.
* ESP-IDF-derived ESP32-S2 USB-console compatibility sources retain their Apache-2.0 notices, with the SDK's Apache license included alongside them. They are historical upstream source and are not built by this original-ESP32-only package.

Research modifications (2026-11-10 through 2026-11-11): original-ESP32 CP2102/UART compatibility settings; bounded detector/pipeline protocols; exact energy kernel; complete guard/clear alternatives; prior validated-buffer overlap; fused full-length validation/copy; DMA-capable guarded paged retention; aligned CAP20 packing; conditional JSON END padding; truthful firmware variant metadata and selected regression tests. Principal changes are in main/targets/esp32, main/Kconfig.projbuild, sdkconfig.defaults.esp32, tools/generate_version.py, FIRMWARE_VARIANT and tests. Original hardware calibration, ownership restoration and full-aperture integrity safeguards are preserved. New headers are part of this GPL project, not separate proprietary components.

Public packaging changes (2026-11-11): build catalog restricted to esp32; top-level CMake rejects other targets; source README/build/provenance documentation replaced with release-specific guidance. These changes do not intentionally modify the ESP32 receiver implementation. Source-only clean build is checked separately; final binaries generated by others must be tested on their hardware.

Excluded: local build directories, artifacts/binaries, logs, RF captures, screenshots, flash/NVS/recovery backups, development notes, absolute personal paths, Git metadata, Python caches/environments and most research tests. The small public tests cover guard equivalence, exact energy arithmetic, ASCII padding and version metadata. Hardware campaign evidence and proprietary SDK binary libraries are not vendored.

Redistribution must preserve applicable GPL/Apache notices and provide corresponding modified source as required. Downloading/linking external ESP-IDF Wi-Fi/PHY libraries introduces their separate Espressif license terms; this source package does not grant additional rights to those libraries. Review those terms before distributing built binaries. No source-license blocker was identified during packaging; this is not legal advice.
